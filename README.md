
Файл glider_env - кастоиное окружение для симуляции полетов модели построенное на основе motoglider.py в этом файле описано получение наград и штрафов за те или иные действия во время симуляции , а так же различные режимы и , уровни сложности

scripts :
make train - для запуска обучения
make watch  - для визуализации работы текщей best_model , по умолчанию она ищется в ./logs/teacher_curriculum_v7/best_model/best_model
make TensorBoard - запускает утилиту tensorboard на 6006 порте , что бы открыть - localhost:6006 в браузере

Так же для корректировки скорости обучения следует корректиторвать количесвто одновременно запускаемых сред n_envs в файле train_teacher_curriculum изменять стоит кратно количеству ядер\потоков вашего cpu
