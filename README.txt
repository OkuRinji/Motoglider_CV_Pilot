Готовая модель мотопланера для MuJoCo
=====================================

Состав
  motoglider.xml   модель MJCF: планер, элероны, руль высоты, руль направления, винт,
                   стереопара, точка датчика ветра, статичные и движущиеся препятствия,
                   маркер цели; все характеристики в разделе custom
  motoglider.py    физика: аэродинамика (обозначения ГОСТ 20058-80), тяга, четыре канала
                   ПИД, ветер, движение препятствий, карта глубины стереопары, столкновения
  check_model.py   проверка модели одной командой
  fly_demo.py      полет в окне MuJoCo с базовым навигатором и вводом цели в консоли

Установка (Python 3.10 или новее)
  pip install mujoco numpy

Проверка
  python check_model.py
  Итог со знаками ✓ и ✗ на один экран, код возврата 0 только если пройдены все проверки.

Демонстрация
  python fly_demo.py
  python fly_demo.py --wind 5 270 --random-obstacles
  Цель: три числа X Y Z и Enter в консоли или перетаскивание красной сферы мышью;
  буква s в консоли ставит внезапное препятствие в 80 м по курсу
  (двойной щелчок по сфере, затем правая кнопка с нажатым Ctrl). На macOS через mjpython.

Как пользоваться в своем коде
  import motoglider as mg
  sim = mg.GliderSim(depth=True)
  s = sim.reset(wind=(5, 270))            # ветер 5 м/с, дует с запада
  s = sim.step(gamma, V, beta, throttle)   # крен, скольжение в радианах; скорость м/с; газ 0...1; шаг 0,1 с
  s = sim.step(gamma, V, beta, throttle, elevator=0.2)   # экстренный режим: руль высоты напрямую, рад
  start, goal, heading = sim.randomize_scene()   # случайная сцена, затем sim.reset(start=..., goal=..., heading_deg=...)
  sim.spawn_obstacle(50)   # внезапное препятствие в 50 м по курсу
  sim.depth(), sim.rays(), sim.obstacles(), sim.wind(), s["crashed"], s["reason"]

Важно
  Если открыть motoglider.xml в обычном simulate, сцена видна, но планер падает:
  подъемную силу MuJoCo не считает, она прикладывается из motoglider.py.
